# 夢見草の夜、君と 公式サイト

乙女ゲーム『夢見草の夜、君と ～想い繋ぐ刻～』の公式サイトです。

## フォルダの中身

| ファイル | 内容 |
|---|---|
| index.html | トップ |
| news.html | ニュース |
| story.html | ストーリー |
| character.html | キャラクター |
| system.html | システム・製品情報 |
| special.html | スペシャル（PV・イベント・壁紙） |
| contact.html | お問い合わせ |
| css/style.css | 見た目（色は先頭の `:root` で変更） |
| js/main.js | 花びら・メニュー・キャラ切り替えの動き |
| images/ | 画像を入れるフォルダ |

## 画像の置き場所

- キービジュアル：`images/kv.webp`
- 立ち絵：`images/chara/yuzuki.webp` など（genma / mitsunari / shion / ryoma / iori）
- スクリーンショット：`images/system/01.webp`〜
- SNS用画像：`images/ogp.jpg`（1200×630）
- タブのアイコン：`images/favicon.png`

各HTMLの「差し替え」と書かれたコメントの位置に、画像のタグを入れてください。
画像はWebP形式に変換し、横幅2000px程度までに縮小してから置くと表示が軽くなります。
